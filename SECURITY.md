# Beveiligingsbeleid

## Een kwetsbaarheid melden
Meld een kwetsbaarheid **niet** in een openbaar issue. Gebruik in plaats daarvan GitHub private vulnerability reporting: ga naar het tabblad *Security* van deze repository en kies *Report a vulnerability* (een security advisory).

We reageren zo snel mogelijk en houden je op de hoogte van de voortgang tot de oplossing is uitgebracht.

## Ondersteunde versies
Alleen de nieuwste release op `main` krijgt beveiligingsupdates.

## Geheimen
Staat er per ongeluk een API-sleutel in de repository of geschiedenis? Meld dat op dezelfde manier en trek de sleutel direct in bij de aanbieder.
